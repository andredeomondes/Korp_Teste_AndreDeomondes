# C# em vez de Go para os microsserviços

O teste permite Golang ou C# para o backend. O autor vem de TypeScript e não tem experiência prévia em nenhum dos dois. Optou-se por C# por proximidade sintática/paradigma com TypeScript (tipagem forte, OOP, async/await) e por ser o stack com mais vagas de estágio backend no mercado brasileiro, reduzindo o risco de aprendizado dentro do prazo de 7 dias.
